# ❌⭕ Jogo da Velha (Tic-Tac-Toe) - React + Vite

## 📄 O que é o jogo?
Esta aplicação consiste em um clássico **Jogo da Velha (Tic-Tac-Toe)** desenvolvido em **React** utilizando a ferramenta de build rápida **Vite**. 

O jogo permite que dois jogadores joguem alternadamente em um mesmo dispositivo, em um tabuleiro 3x3. Além da lógica tradicional de vitória e empate, esta versão possui melhorias arquiteturais e visuais em relação ao tutorial oficial do React:
- **Estilização Modulada:** Uso de **CSS Modules** combinados com variáveis CSS e metodologia **BEM** para evitar vazamento de estilos globais.
- **Layout Responsivo:** Integração com **Bootstrap** para alinhamento rápido e adaptabilidade a diferentes tamanhos de tela.
- **Componentização:** Separação clara de responsabilidades entre componentes (`Square`, `Board`, `Game`, etc.).
- **Histórico de Jogadas:** Funcionalidade de "viagem no tempo" para navegar pelas jogadas anteriores da partida.

---

## 🎯 Objetivo da atividade
O objetivo deste projeto é refatorar a implementação padrão do tutorial oficial do React, aplicando conceitos avançados de Front-end para criar uma aplicação robusta, sustentável e bem estruturada.

**Conceitos aplicados no projeto:**
- Componentização, composição e reutilização de interfaces.
- Gerenciamento de estado com o hook `useState` e imutabilidade de dados.
- Passagem de dados e rotinas via `props`.
- Organização modular de estilos usando **CSS Modules** e **BEM**.
- Boas práticas de **Clean Code**, HTML semântico e acessibilidade.
